# M6 · Pro 会员

- **分支**：`stage/m6-pro`
- **目标**：录音和评分拆开，评分改成可选；加入 Pro 会员和免费体验次数，由管理员手动开通；大模型改为只用管理员的统一配置。

## 来源

使用者 2026-10-10 提出的两个需求，讨论后定下的细节：

1. **录音和评分拆开**：背完一遍先存下来，能回放；评分自己选择做不做；没评分的录音也能分享给朋友听。
2. **Pro 会员**：9.9 元/月。Pro 不限次数；非会员从第一次使用起，一共只有 5 次体验。

### 为什么这次不接支付

- 会员属于虚拟商品，平台要求用「小程序虚拟支付」，不能用普通的微信支付。个人主体本来也开不了普通微信支付。
- 个人主体开虚拟支付要先完成认证和备案，服务类目里要有「工具」，并且和实际功能相符。这条消息来自第三方文章，没找到微信官方公告；体验版能不能收真钱也没查到官方说明。
- 按月自动续费要求小程序发布满 90 天、日活 1 万以上，做不了。以后接上支付，也只能做成"9.9 元买 30 天"。

所以这次先把会员体系做完，Pro 由管理员手动开通（朋友付款后，你在小程序里给他开）。使用者在后台确认能开虚拟支付以后再接，到时只是多一种开通方式，会员体系不用动。

## 规则

| 项目           | 规则                                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 免费体验       | 每人一共 5 次，不按月重置。**新建对话**（生成第一版英文，含解析）和**评分**都扣 1 次，两者合计                                 |
| 不扣次数的操作 | 同一个对话里的多轮修改、切换版本、示范朗读、背诵录音、回放、分享（包括分享时为了对齐歌词做的识别）                             |
| 失败不扣       | 发起时先占用 1 次，任务失败就退回；同一个对话或同一条录音重试时，不会重复扣                                                    |
| 何时开始计数   | 上线这天开始，以前生成的对话和评分都不算                                                                                       |
| Pro            | 不限次数。管理员每开通一次加 30 天：没开通或已过期的从当天起算，还没到期的在到期日上往后加。到期后回到免费状态，剩余次数接着用 |
| 管理员         | `ADMIN_OPENIDS` 里的人一直按 Pro 算，不受次数限制                                                                              |
| 次数用完       | 发起新对话或评分时弹出 Pro 介绍（价格、权益、"付款后联系管理员开通"、复制用户 ID），不发起任务；已有的对话、报告照常能看       |
| 大模型配置     | 成员不能再填自己的配置，生成、评分都用管理员的全局配置。成员以前存的配置（包括加密的 Key）从库里清除                           |

## 验收标准

1. 背完一遍直接进入练习记录页，能回放；不评分也能分享，好友打开后歌词同步滚动、逐词点亮，和评过分的一样准
2. 在练习记录页点「评分」，得到和现在一样的报告
3. 免费成员新建对话和评分合计 5 次，「我的」页和发起时都能看到剩余次数；第 6 次时弹出 Pro 介绍，不发起任务
4. 生成或评分失败不扣次数；修改、切换版本、分享不扣次数
5. 管理员在「会员管理」给成员开通后，该成员马上不受次数限制，「我的」页显示到期日；结束 Pro 后回到免费状态，剩余次数接着用
6. 管理员自己不受次数限制
7. 成员在「我的」页看不到大模型配置，生成和评分都能正常用管理员的配置
8. 浅色、深色都正常

# M3 · 收藏与历史

- **分支**：`stage/m3-library`
- **目标**：收藏对话和表达 / 单词，按文件夹和标签整理；打开表达卡片能溯源到原句，并看到它在其他对话里的用处；所有对话可在历史页查找。

## 已敲定的选择（2026-10-09）

| 问题             | 选择                                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------- |
| 收藏页结构       | 收藏页顶部切换「表达」「对话」，只放主动收藏的；全部历史在练习页「最近对话 → 查看全部」，带搜索 |
| 单词 / 短语释义  | 解析里的关键表达、俚语直接用解析内容；从句子或报告里收藏的，由大模型按原句语境补全              |

| 复习             | V2 再做                                                                                         |

## 默认方案（待使用者确认）

### 收藏入口

- **对话**：对话页标题栏的收藏图标（和「收藏」tab 同一个书签图标）。点一下收进「未归类」；再点一次取消收藏（只取消收藏，对话本身还在历史里）
- **解析里的表达**：关键表达、俚语每一条右侧有收藏图标，点一下收藏；已收藏的显示实心，再点打开卡片
- **英文句子里的词**：对话页长按一句 → 选词面板，点一个词收藏单词，先后点首尾两个词收藏中间的短语（点句子重听保持不变）
- **评分报告里的词**：点单词弹出的详情面板加「收藏」按钮
- 收藏成功轻微震动，底部浮出「已收藏 · 选文件夹」提示，3 秒后消失；点「选文件夹」打开文件夹选择（开发时改为提示而不是直接弹面板，连续收藏时不打断）

### 表达卡片

- 内容：表达本身、中文释义、用法说明、例句、我的备注（可编辑）、标签、所在文件夹
- 大模型补全按设置里的英语水平写；补全期间卡片先显示，释义处显示"正在生成…"，失败可重试
- **合并**：忽略大小写、首尾标点和多余空格后相同的算同一张卡片；再次收藏只累加来源，同一句不重复记
- 取消收藏 = 删除卡片（二次确认）

### 溯源

- **收藏自**：每条来源显示那句英文（表达高亮）、对话标题、日期；点进去打开对话，切到那个版本并滚动高亮那一句
- **也出现在**：在你所有对话、所有版本的英文里查找，排除已在「收藏自」里的句子，最多 20 条，最新的在前
- 匹配规则：大小写和标点不敏感；常见词形变化（-s / -es / -ed / -ing、双写辅音、去 e、约 150 个常用不规则动词）；短语里的 sb / sth / someone / something / one's 可匹配 1～3 个任意词

### 文件夹与标签

- 两栏共用一套文件夹；最多 3 级
- 新建、重命名、移动（移动后整棵子树不能超过 3 级）、删除（弹窗选：内容移到上一级 / 一起删除。一起删除时对话只是取消收藏，表达卡片会删除）
- 排序：文件夹在编辑模式里上移 / 下移；文件夹里的收藏按收藏时间倒序
- 一个收藏只在一个文件夹里，或在「未归类」；标签可以有多个（每个收藏最多 10 个，每个标签最多 12 个字）
- 浏览像「文件」App 一样逐级进入：根目录先列一级文件夹，下面直接列未归类的收藏；顶部一排标签，点一个只看带这个标签的（再点取消）
- 收藏页顶部是「表达 / 对话」切换和搜索框（像 iOS 的搜索栏，比藏在右上角更顺手）：表达搜文本、释义、备注，对话搜标题、原文、润色中文和英文；大标题右侧的 + 新建一级文件夹

### 历史

- 练习页「最近对话」加「查看全部」→ 历史页：全部对话按更新时间倒序，下拉加载更多
- 搜索标题、中文原文、润色后的中文、所有版本的英文
- 删除对话不在本阶段

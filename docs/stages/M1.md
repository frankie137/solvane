# M1 · 表达生成

- **分支**：`stage/m1-compose`
- **目标**：说一段（或打一段）中文，得到流畅的中文、地道的英文和解析，并能继续提要求修改。

## 关键设计

### 交互流程

1. **语音输入**：练习页按住麦克风说话，最长 60 秒，不足 1 秒提示"说话时间太短"；按住时上滑可以取消（和微信语音消息一样）。录音时显示实时音量波形。
2. **确认原文**：松手后上传录音、识别成文字，弹出底部面板显示识别结果，可以修改；打字输入也用这个面板。
3. **生成**：点"生成地道表达"后立刻进入对话页，先显示骨架屏，依次出现：整理后的中文和英文 → 解析。
4. **修改**：对话页底部有输入框和快捷要求（更随意、更正式、更简短、加点俚语），每次修改生成一个新版本，可以在版本之间切换。

### 后端任务模型

- 小程序端调用云函数默认大约 15 秒就不再等结果，而大模型生成可能更久。因此生成类请求的结果一律**先写进数据库**；前端等不到返回时，改为每 2 秒查询一次对话状态，最多等 70 秒。
- 每个对话同一时间只运行一个任务（生成、修改或解析），用数据库的条件更新加锁，避免重复生成。运行超过 70 秒的任务视为中断，允许重试。
- 生成分两步：第一步出整理后的中文、英文主推版、中英逐句对照、备选说法和标题；第二步出解析。

### 云函数与接口

| 云函数    | action                                              | 说明                                             |
| --------- | --------------------------------------------------- | ------------------------------------------------ |
| `compose` | `create`                                            | 新建对话（只写原文），立即返回 id                |
|           | `generate`                                          | 生成第一版                                       |
|           | `revise`                                            | 按修改要求生成新版本                             |
|           | `analyze`                                           | 为某个版本生成解析                               |
|           | `getLlmConfig` / `saveLlmConfig` / `testLlm`        | 大模型配置的读取、保存、测试连接                 |
| `speech`  | `recognize`                                         | 中文语音识别（腾讯云一句话识别），识别后删除录音 |
| `data`    | `getSettings` / `updateSettings`                    | 英语水平、口音                                   |
|           | `getSession` / `listSessions` / `setCurrentVersion` | 读取对话、最近对话、切换版本                     |

需要密钥的逻辑集中在 `compose` 和 `speech`，`data` 不需要任何环境变量。

### 大模型

- 兼容 OpenAI 接口的通用客户端，预设 DeepSeek、通义千问、Kimi、智谱、豆包和自定义，预设只负责填好接口地址，模型名可以改。
- 要求输出 JSON，用 schema 校验；服务商不支持 JSON 模式时自动去掉该参数重试；校验失败重试一次。
- 用户输入在提示词里明确标注为"待处理的内容"，不当作指令执行。
- API Key 用 AES-256-GCM 加密存库，前端只能看到打码值；接口地址只允许 https 的公网域名。
- 读取顺序：自己的配置 → 管理员的全局默认 → 提示去配置。

### 录音

- 格式 PCM、16kHz 单声道，便于计算实时音量；60 秒约 1.9 MB。
- 识别完成后立即删除录音文件，不长期保存。

- [ ] `data` 云函数：设置、对话读取、最近对话、切换版本

## 需要使用者准备（端到端验证前）

2. **腾讯云**：开通"语音识别"，创建只授权语音识别的子账号密钥
3. **云函数配置**（部署后在云开发控制台设置）：
   - `compose`：超时 60 秒；环境变量 `KEY_ENCRYPTION_SECRET`（随机字符串）、`ADMIN_OPENIDS`（你的用户 ID）
   - `speech`：超时 20 秒；环境变量 `TENCENT_SECRET_ID`、`TENCENT_SECRET_KEY`
   - `data`：超时 10 秒
4. **用户隐私保护指引**：公众平台「设置 → 服务内容声明 → 用户隐私保护指引」中声明使用麦克风
5. **大模型 API Key**：在小程序「我的 → 大模型配置」里填写

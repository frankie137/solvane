# M2 · 朗读与背诵评测

- **分支**：`stage/m2-recite`
- **目标**：听示范朗读，遮住原文背一遍，得到发音、流利度、内容还原、表达正确性四项评分和具体建议。

## 已敲定的选择（2026-10-09）

| 问题               | 选择                                                                                   |
| ------------------ | -------------------------------------------------------------------------------------- |
| 背诵时原文怎么显示 | 默认遮住；点「提示」先显示每个词的首字母，再点显示整句；也可以单独点某一句逐级提示     |
| 示范朗读音色       | 腾讯云大模型音色：WeWinny（女，501009）/ WeJames（男，501008），设置里可切男女声和语速 |
| 示范朗读高亮       | 读到哪个词哪个词高亮；点某一句只重听这一句                                             |
| 报告里点单词       | 弹出这个词的问题（哪个音没发好、怎么发），可以听标准发音，也可以听自己录音里的这一小段 |

## 调研结论对设计的影响

- 口语评测新版只有 WebSocket 接口、没有 Node SDK：在云函数里用 `ws` 自己实现，签名按官方文档（HMAC-SHA1）。基础版已于 2026-06 停售
- 自由说模式不返回时间戳和音素：第一步改用腾讯云**英文一句话识别**（`16k_en`，带词级时间戳）得到"实际说了什么"
- 只有句子模式（≤30 词）返回音素和时间：按句切分录音，每句单独用句子模式评测；超过 30 词的句子改用段落模式（只有分数）
- 一次评测放不进单次云函数 60 秒：拆成多步，前端依次推进，每步都写库，超时后可以轮询结果
- 示范朗读英文每次最多 500 个字母：按句合成并缓存；腾讯云没有英式音色，口音选英式时示范仍是美音

## 背诵评测流程

| 步骤   | 做什么                                                               | 产出                                                       |
| ------ | -------------------------------------------------------------------- | ---------------------------------------------------------- |
| ① 识别 | PCM 转成 WAV 存档（用于回放），英文一句话识别                        | 实际说出的词和每个词的时间                                 |
| ② 对照 | 大模型对照"实际说的"和原文，逐句还原"你想说的那句话"，给每处差异分类 | 每句的还原文本和时间范围、差异列表、内容还原度、表达正确性 |
| ③ 评测 | 按句切出录音片段，以还原文本为参考，用句子模式并行评测               | 每个词的精准度、音素问题，整体精准度、流利度、完整度       |
| ④ 报告 | 大模型根据前几步的结果写建议                                         | 总分、一句话总结、发音建议、背诵建议                       |

- 差异分类：读错了（按发音问题处理）、换了说法（意思对、表达地道，不扣分）、漏说、多说、语法错误
- 评分：发音 40% + 流利度 20% + 内容还原度 25% + 表达正确性 15%
- 每一步在云函数里有 55 秒预算；每个练习同时只运行一步（和 M1 一样的任务锁）

## 数据

- `practices`：`_openid`、`sessionId`、`vid`、`stage`（transcribe → align → score → report → done）、`job`、`lastError`、`audio{wavFileID, durationMs}`、`transcript`、`alignment`、`pronunciation`、`report`、`createdAt`、`updatedAt`
- 每个对话保留最近 3 次练习，新练习创建时删除更旧的（连同录音文件）

- 学习偏好新增 `ttsVoice`（female / male）、`ttsSpeed`（normal / slow）

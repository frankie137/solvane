# M8 · README showcase

- **Branch**: `stage/m8-showcase`
- **Goal**: show what Solvane does at a glance at the top of the README, and give the owner a short video to post.

## Origin

On 2026-10-13, after the repository went public, the owner asked for a showcase animation modeled on one of the videos collected in [awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos), and picked the "one shape, never cut" UI motion piece out of three candidates. Decisions:

| Topic    | Decision                                                                                                                                                                                                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Story    | One card morphs through the core flow without a cut: mic → recording → confirm the transcript → polished Chinese and idiomatic English → key expression and Chinglish comparison → demo reading → recite → score → lyrics share page, whose "I want to practice too" (「我也来练」) button leads back to the mic |
| Example  | Telling the boss a project will slip: 「就是…那个项目吧，可能要晚两天，嗯，但是质量会更好」 → _Just a heads-up: the project might slip by a couple of days. But it'll be in much better shape._                                                                                                                  |
| Fidelity | Real UI text, components and tokens from the mini program (sizes, radii, colors, the score ring's tone colors, the lyrics stage); a touch indicator instead of a mouse cursor; English captions and a progress row outside the card explain each step                                                            |
| Format   | 1440×1440, 16 s at 120 BPM (8 bars, every tap on a beat), seamless loop; light and dark versions                                                                                                                                                                                                                 |
| Output   | The README plays the light MP4, uploaded by the owner as a GitHub attachment because GitHub can't play a committed MP4 inline. Dark WebP and MP4s with music in both themes are kept in `docs/showcase/` for later use                                                                                           |
| Music    | "Pop 09" by Grigoriy Nuzhny (Mixkit Stock Music Free License), from 48 s to 64 s: 8 bars that start and end on the same section's bar lines. The license forbids redistributing the audio itself, so the track stays out of the repository                                                                       |
| Tools    | Playwright and ffmpeg-static are not project dependencies; `pnpm showcase` loads them from a directory named by `SHOWCASE_TOOLS`                                                                                                                                                                                 |

## Tasks

- [x] `docs/showcase/flow.html`: one self-contained page; `seek(t)` computes every style from time with closed-form springs (no CSS transitions, timers or carried state); `?theme=dark`, `?render` and `?t=` parameters; preview controls when opened directly
- [x] `scripts/showcase.ts` (`pnpm showcase`): renders 60 fps frames in headless Chromium and pipes them to ffmpeg; writes `docs/showcase/flow-<theme>.webp` (960 px, 30 fps) and `docs/showcase/flow-<theme>.mp4` (1440 px, 60 fps, optional music)
- [x] README: a marked spot for the video under the badges, with the light WebP standing in
- [x] Owner: upload `docs/showcase/flow-light.mp4` in GitHub's web editor in place of the WebP
- [x] `CLAUDE.md`: `pnpm showcase` in the common commands

## Acceptance criteria

1. `pnpm check` passes.
2. The README plays the light showcase video on GitHub.
3. Every UI string, label and score in the animation matches the mini program; only the session title and the sharer's nickname are made up.
4. The first and last frames match, so the WebP and MP4 loop without a jump.
5. Taps land on the music's beats in the MP4.
6. No audio file is committed.

# M5 · 打磨

- **分支**：`stage/m5-polish`
- **目标**：全流程顺畅、稳当：每个异步操作都有加载、空、出错三种状态和重试；点按区域够大、有按下反馈；内容出现有过渡；文案统一；临时链接过期、连点、切后台这些边角情况都处理好。

## 来源

使用者真机使用下来没有特别的问题，按逐页检查的结果打磨（2026-10-10，后台检查代理逐页审查，40 条）。包体积已检查：主包约 0.7 MB、分包都在 130 KB 以内、按需加载组件已开启，本阶段不需要优化体积。

## 决定不改的

| 检查发现                                                                          | 不改的理由                                                                                                                               |
| --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 技术性的错误提示（如「请检查 assess 云函数的 SOE_APP_ID」、带错误码）直接给用户看 | 小程序只以体验版在小圈子里使用，使用者同时是管理员；M2 联调正是靠详细提示定位到 AppID 填错。改成笼统提示会让排查变难，实时日志只作为补充 |
| 「我的」页的用户 ID、云服务延迟、「好友需要是体验成员」等按正式版隐藏             | 不会发布正式版；这些信息在体验版里有用（「需要是体验成员」是真实限制）                                                                   |

## 任务清单

### 出错日志

- [x] 云函数调用失败、未捕获的异常写入微信实时日志（只记位置、错误码和文案，不记内容）；正常的业务结果（参数不对、找不到、已取消）不记

### 状态与重试

- [ ] 报告页：加载失败单独显示「报告加载失败」和重试；打开已完成的报告时先显示骨架，不闪「正在评测」
- [ ] 重试时不闪空状态（收藏列表、全部对话、我的分享），重试按钮显示加载中
- [ ] 「我的」页：设置加载失败时，点英语水平等行可以重新加载；资料加载失败可重试
- [ ] 收藏列表已有内容时刷新失败，在列表上方提示「没能刷新 · 重试」；文件夹数据还没到时算加载中，避免页面跳动
- [ ] 全部对话翻页失败时底部显示「加载失败，点此重试」
- [ ] 语音识别失败时可以「重新说一次」
- [ ] 背诵提交失败时保留录音，可以「重新提交」，不用重背
- [ ] 表达卡片在文件夹数据没到时文件夹一栏显示「—」，不误显示「未归类」
- [ ] 歌词页加载中用深色骨架
- [ ] 清除大模型配置时有加载状态和「已清除」提示

### 点按区域与按下反馈

- [ ] 基础组件：面板关闭按钮、chip、小号按钮的点击区扩到 44px（视觉不变）
- [ ] 小图标按钮（搜索清除、修改栏发送、复制、收藏、全部、排序、添加、新建、更多、发音、进度条、重新加载、收藏提示操作）统一 44px 点击区
- [ ] 可点但没有按下反馈的元素补上（歌词行、挑词的词块、报告里的单词、修改栏发送）

### 动效

- [ ] 全局一次性的出现动画 `.sv-appear`，骨架换成内容时淡入
- [ ] 报告页评分条从 0 增长到分数，和分数环同步
- [ ] 背诵面板三种状态交叉淡入、高度固定
- [ ] 歌词页「录音没能加载」淡入，不顶开控件

### 设计变量

- [ ] 转圈动画的时长和关键帧收成一份（`--sv-dur-spin`、全局 `sv-spin`）
- [ ] 波形条的过渡时长和录音刷新间隔用同一个值，注明关联
- [ ] 溯源突出一句的动画时长和清除时间用同一个常量
- [ ] 光晕阴影收成 `--sv-shadow-glow`

### 文案

- [ ] 统一用词：出错标题「X 加载失败」、兜底「出了点问题，请重试」、「请稍后再试」、「重试」；「再背一次」「去练习」
- [ ] 取消收藏卡片的确认按钮改为「删除卡片」，不和系统的「取消」混淆
- [ ] 「最长 60 秒」从限制常量生成

### 稳定性

- [ ] 临时链接过期：「我的」页头像、报告页回放超过 90 分钟或播放出错时重新获取；示范朗读播放出错时作废缓存；歌词页重新加载后回到原来的位置
- [ ] 跳转防连点：统一的 `navigateOnce()`，替换所有跳转
- [ ] 防重复提交：对话页收藏、解析收藏
- [ ] 录音时切到后台：取消这次录音并提示，不让计时继续走
- [ ] 卸载时清掉所有定时器；报告页、大模型配置页、我的分享页底部留出安全区

## 验收标准

1. `pnpm check` 全部通过
2. 静态检查通过后，经使用者同意再做开发者工具截图检查
3. 真机：断网或飞行模式下打开各个页面，都有出错提示和重试，恢复网络后点重试能加载
4. 真机：快速连点任意入口只打开一个页面；连点收藏只收藏一次
5. 真机：录音或背诵中切到后台再回来，状态正确
6. 真机：全流程走一遍（说一段话 → 修改 → 背诵 → 报告 → 收藏 → 分享），过渡顺滑，深浅色都正常

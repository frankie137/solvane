# M4 · 分享

- **分支**：`stage/m4-share`
- **目标**：选一次背诵录音，以小程序卡片发给微信好友；对方打开后像网易云歌词页一样，边听边看中英文，读到哪句高亮哪句。

## 已敲定的选择（2026-10-10）

| 问题     | 选择                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| 高亮方式 | 逐句高亮并滚到中间；当前句里读到哪个词哪个词点亮（没有单词时间的句子只整句高亮） |
| 卡片封面 | 自动生成：渐变背景 + 标题 + 第一句英文                                           |
| 署名     | 第一次分享时用微信的头像昵称填写组件设置一次，之后在「我的」页可改               |
| 分享管理 | 「我的」页列出分享过的，可以撤回；撤回后链接失效、录音副本删除                   |
| 分享内容 | 只有录音和中英原文，不含分数和解析（README 已定）                                |
| 可见范围 | 接收人需是小程序的体验成员（README 已定）                                        |

## 默认方案

- **入口**：评分报告底部「分享这次背诵」。还没设置头像昵称时先弹出设置面板；然后生成分享，打开歌词页预览，页面底部「发给朋友」直接调起微信分享
- **同一次练习只生成一个分享**：再次分享直接用已有的
- **录音副本**：生成分享时把录音复制一份到 `shares/`，练习记录被清理（每个对话只留最近 3 次）也不影响已分享的链接
- **歌词页**：
  - 固定为沉浸式深色（像网易云播放页），不跟随系统
  - 英文一行、中文一行；当前句放大高亮、平滑滚到屏幕中间，其余句子变暗
  - 点某一句从那里播放；底部播放 / 暂停、可拖动的进度条和时间
  - 手动滚动后 3 秒内不自动跟随
  - 没背出来的句子也显示原文，但不高亮、不能点
  - 顶部显示标题和「某某的朗读」（头像 + 昵称）
- **接收人**：打开卡片直接进歌词页；分享已撤回时显示"分享已撤回"；底部「我也来练」进入首页
- **我的分享**：「我的」页新增一行，列出标题、第一句、日期；点开进歌词页，可再次发出或撤回
- **头像昵称**：「我的」页顶部的资料卡改为可点，修改头像和昵称；头像上传到 `avatars/`
- **封面**：在歌词页用隐藏的画布画 5:4 的图，作为分享卡片的图片；画布不能用 CSS 变量，颜色取自设计变量的渐变色，集中定义在一处

## 数据

| 集合       | 变化                                                                                                                                                                      |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `settings` | 新增 `profile{nickname, avatarFileID}`                                                                                                                                    |
| `shares`   | `_openid`、`sessionId`、`practiceId`、`title`、`sentences[]{en, zh, startMs, endMs, words[]}`、`audioFileID`、`durationMs`、`author{nickname, avatarFileID}`、`createdAt` |

`words[]` 与示范朗读的逐词时间同一结构（时间 + 在原句里的字符位置），由评测结果里的单词对到原句上得到。

## 云函数

- `data`：`getProfile`、`updateProfile`、`createShare`、`getShare`（任何人凭链接可读，只返回快照字段和临时链接）、`listShares`、`revokeShare`
- 不新增云函数（`data` 的 10 秒足够复制 2 MB 以内的录音）

## 页面

- `pkg-share/play`：歌词播放页（自己预览 / 好友打开共用）
- 「我的」页：资料卡可编辑、「我的分享」
- `pkg-share/mine`：我的分享列表
- 报告页：「分享这次背诵」

## 验收标准

3. 真机：从报告页分享，设置头像昵称后看到歌词页预览，发给体验成员好友，卡片封面正常

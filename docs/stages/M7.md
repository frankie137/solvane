# M7 · Open-source preparation

- **Branch**: `stage/m7-open-source`
- **Goal**: make the repository safe and readable for the public: add a noncommercial license, move all developer-facing text to English, and remove operational details that do not belong in a public repo.

## Origin

On 2026-10-13 the owner asked whether the repository could be published without leaking anything, then asked for a noncommercial license and for the whole repository to be switched to English. Decisions:

| Topic                    | Decision                                                                                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| License                  | [PolyForm Noncommercial 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0): free for personal, research and nonprofit use; no commercial use. Described as "source-available", not "open source" |
| UI text                  | Stays Chinese. The product is for Chinese speakers; anything a mini program user can see (templates, toasts, `AppError` messages) is unchanged   |
| LLM prompts              | Stay Chinese. Prompts drive output quality, and changing their language would mean re-tuning                                                      |
| Developer-facing text    | English: code comments, test titles, script output, logs, config comments, all docs                                                               |
| Stage docs M0–M6         | Condensed into an English `CHANGELOG.md`; deployment records, environment IDs, incident details and acceptance notes are dropped                |
| Working language         | The owner and Claude keep chatting in Chinese; everything written into the repository is English from now on                                     |

### Findings of the leak check

No secret was ever committed: `.keys/`, `cloud.env`, `.env.local` and `*.key` never entered history, no binary files were ever committed, commit authors use the GitHub noreply address, PR bodies are clean, and CI uses no secrets. Items handled in this stage:

- The docs said the code-upload IP whitelist is disabled. Not needed by the public and helpful to an attacker who obtains the upload key, so it is removed.
- A stage doc contained the CloudBase environment ID. It is not a secret (it is compiled into the mini program bundle), but it is dropped with the stage docs.
- The AppID stays: it is public by nature and the project needs it.
